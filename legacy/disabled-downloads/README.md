# Архив отключённого получения файлов

Эти три файла сохранены как история собственной реализации: прежний загрузчик,
проверка медиаданных и импорт завершённых файлов. Установщик их **не устанавливает**,
Transmission и ffplayout для них не ставит, таймеры не создаёт.

Текущая переносимая версия панели всегда отклоняет торрент-операции.
Сохранение исходников не означает, что старые источники подключены или разрешены.
Новый способ получения контента должен подключаться отдельно, с проверкой источника,
прав использования, размера файла, свободного места и звуковых дорожек.
