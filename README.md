# CYRIUS TV — кинозалы и панель управления

Переносимая версия проекта: **семь круглосуточных каналов**, веб-панель на русском,
очереди, логотипы, название фильма и XMLTV/ЕПГ. Основная цель этого репозитория —
развернуть систему на другом сервере без поиска инструкций в переписке.

**Начните с [установки на чистую Ubuntu](docs/INSTALL.md).** Для переноса уже
существующих фильмов и настроек есть отдельная [инструкция миграции](docs/MIGRATION.md).

## Что входит

| Часть | Где лежит код | Назначение |
|---|---|---|
| Интерфейс | `src/panel/static/` | Каналы, очередь, медиатека, оформление, ЕПГ, сервер |
| Backend | `src/panel/app.py` | Flask API, вход, управление и состояние |
| Эфир | `src/playout/cyrius-copy-playout.py` | Выбор фильма, запуск FFmpeg, HLS |
| Оформление | `src/playout/cyrius_branding.py`, `cyrius_caption.py`, `cyrius_picture.py` | Логотип, название, формат кадра |
| Очереди | `src/playout/cyrius_queue.py` | Порядок фильмов, повтор, подтверждение команд |
| ЕПГ | `src/playout/cyrius-programme.py` | XMLTV и программа на 24 часа |
| Установка | `deploy/install.py` | Конфигурация, права, службы, Nginx |
| Администрирование | `scripts/admin.py` | Начальный пароль, его сброс, HTTPS, диагностика |
| Оформление CYRIUS | `assets/` | Семь логотипов, Montserrat Light и лицензия шрифта |

Каналы: **Боевики, Comedy, Kids HD, Horror, Cinema HD, Ретро HD, Романтика HD**.
Cinema использует общую подборку шести тематических библиотек без копирования фильмов.

## Как работает показ

```text
Медиатека → очередь канала → Python + FFmpeg → HLS через Nginx
                                                     ↓
                                           ваш Flussonic → зрители

Браузер → HTTPS-панель → команды очереди / настройки оформления
```

По умолчанию: 1920×1080, заполнение 16:9 с обрезкой краёв без растяжения,
исходная частота кадров, логотип справа сверху, название слева сверху.
Оформление требует перекодирования видео и расходует CPU. Звук выбирается с
приоритетом русской дорожки и кодируется в AAC-LC, стерео, 48 кГц, 160 кбит/с.

## Что здесь принципиально отсутствует

* Фильмы и загрузки. Для нового сервера создаётся только техническая заставка.
* Пароли, приватные ключи, TLS-сертификаты, сеансы и рабочая база пользователей.
* Настройки дисковых разделов, форматирование и автоматическое изменение RAID.
* Установка или лицензия Flussonic.
* Работающий торрент-загрузчик. Transmission и автоподбор отключены; старая
  реализация хранится отдельно в `legacy/disabled-downloads/` и не устанавливается.

Новый сервер получает новый пароль и новый HTTPS-сертификат. Для доступности
источника извне нужно явно указать IP вашего Flussonic в `origin_allow`.

Целевая ОС — **Ubuntu 24.04**. Один диск поддерживается; второй подключается
только как уже смонтированное хранилище. ffplayout текущему движку не требуется.

Установщик проверяется через `--check` и `--render-dir` без изменения системы.
`--apply` предназначен для **чистого сервера**: при обнаружении существующей
установки CYRIUS или занятых портов он останавливается.

Рабочий сервер не обновляется автоматически при изменении GitHub-репозитория.
