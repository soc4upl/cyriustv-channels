# Установка на новый сервер

## 1. Подготовка

Нужна чистая Ubuntu 24.04, SSH и sudo. Порты 80, 443, 8890 и 18080 не должны
использоваться другими приложениями. Ничего удалять для освобождения портов
установщик не будет: существующий Nginx требует ручного объединения настроек.

Заранее создайте A-запись домена панели на IP нового сервера. Если есть AAAA,
она тоже должна вести на этот сервер. Для сертификата нужен входящий TCP 80.
Проксирование DNS/CDN на время первоначальной настройки лучше не использовать.

Выполните **на новом сервере**, а не на Mac:

```bash
sudo apt-get update
sudo apt-get install -y git
git clone https://github.com/soc4upl/cyriustv-channels.git
cd cyriustv-channels
cp deploy/settings.example.json deploy/settings.json
nano deploy/settings.json
```

Репозиторий закрытый: используйте свой GitHub SSH-ключ либо обычный вход через
GitHub CLI. Токены не вставляйте в URL и не сохраняйте в файлах проекта.

## 2. Заполните настройки

| Поле | Что указать |
|---|---|
| `panel_domain` | Ваш домен панели, без `https://` |
| `origin_base_url` | Адрес нового источника, например `http://IP_СЕРВЕРА:18080` |
| `timezone` | По умолчанию `Asia/Baku` |
| `secondary_storage` | `false` для одного диска; `true` только для подготовленного второго |
| `origin_allow` | IP/CIDR серверов Flussonic, которым разрешено забирать HLS |
| `admin_username` | Логин панели, по умолчанию `admin` |

Пример `origin_allow`: `["127.0.0.1", "198.51.100.20"]`.
`198.51.100.20` — пример, замените настоящим адресом CDN. Значение `["all"]`
открывает источник всем; использовать его следует только осознанно.

`origin_base_url` обозначает адрес, который будет указан в M3U/ЕПГ. Это не адрес
веб-панели и не адрес Flussonic. IPv6 в этом поле пока не поддерживается.

Для второго диска сначала отдельно настройте его постоянное монтирование
в `/srv/cyrius/disk2`. Установщик проверит отдельную файловую систему и создаст
bind-монтирования медиапапок. Он **не форматирует диски и не меняет RAID**.

## 3. Проверьте и установите

```bash
python3 deploy/install.py --config deploy/settings.json --check
python3 deploy/install.py --config deploy/settings.json --render-dir rendered
sudo python3 deploy/install.py --config deploy/settings.json --apply
```

`rendered/` создаётся только в новом каталоге. Его содержимое можно просмотреть
перед установкой: это будущие конфиги Nginx, systemd и каналов.

Устанавливаются пакеты Ubuntu: FFmpeg, Flask, Werkzeug, Pillow, Gunicorn,
Nginx, Certbot и sudo. Бинарные сборки с прежнего сервера не нужны.

Установщик создаёт пользователя `ffpu`, группу `cyrius-media`, закрытую базу
панели, новый случайный пароль и 12-секундную техническую заставку. Он запускает
backend панели и таймер ЕПГ. **Семь видеоканалов сразу не запускаются**, чтобы
сначала проверить нагрузку на одном канале.

План перед выполнением не проверяет доступность домена и сертификат. Если
установка оборвалась посередине, не удаляйте каталоги автоматически: сохраните
вывод ошибки и разберите причину. Повторный `--apply` защищён от перезаписи.

## 4. Включите HTTPS

На этом этапе HTTP-домен панели отвечает 503: форма входа до HTTPS не публикуется.

```bash
sudo cyrius-admin tls --email ВАШ_EMAIL
sudo cat /root/cyrius-panel-credentials.json
```

Certbot предложит принять условия центра сертификации. Войдите на
`https://ВАШ_ДОМЕН` с новым паролем. На новом сервере пароль будет отличаться
от старого. Автопродление сертификата включается вместе с HTTPS.

Откройте TCP 80/443 в существующем сетевом экране. TCP 18080 разрешите для CDN.
Установщик **не включает и не переписывает firewall**, чтобы не потерять SSH.
Порт 8890 слушает только localhost и наружу не открывается.

## 5. Запустите первый канал

```bash
sudo systemctl enable --now cyrius-copy@1.service
sudo journalctl -u cyrius-copy@1.service -n 30 --no-pager
curl --fail http://127.0.0.1:18080/cyrius-boeviki/index.m3u8
```

Для локальной проверки `127.0.0.1` должен быть в `origin_allow`.
Без фильмов будет техническая заставка с оформлением. После проверки CPU и
воспроизведения можно запускать остальные службы по одной:

```bash
sudo systemctl enable --now cyrius-copy@2.service
```

Аналогично используются номера 3–7. Одновременное Full HD-перекодирование семи
каналов требует существенного CPU; 32 ГБ RAM не заменяют видеокодирование.

## 6. Добавьте контент и подключите CDN

Разместите проверенные фильмы с разрешением на показ в нужных папках из
[таблицы каталогов](ARCHITECTURE.md). Завершайте загрузку во временный файл
с расширением `.part`, затем атомарно переименовывайте в `.mkv` или `.mp4`.
Дайте `ffpu` право чтения файла и прохода по родительским каталогам.

Пересканирование очереди происходит при переходе на следующий фильм или
сохранении очереди через панель. Не копируйте изменяющийся файл прямо под
окончательным именем в медиатеку.

Во Flussonic создайте поток с HLS-источником:

```text
hls://IP_НОВОГО_СЕРВЕРА:18080/cyrius-boeviki/index.m3u8
```

Для каждого канала свой slug из `ARCHITECTURE.md`. Адрес ЕПГ:
`http://IP_НОВОГО_СЕРВЕРА:18080/epg.xml`.
Проверяйте доступность **с CDN**, а не только с самого нового сервера.
