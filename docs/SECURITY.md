# Доступ и хранение данных

* Публичный вход в панель — HTTPS с паролем. Backend слушает localhost:8890.
* Cookie: HttpOnly, SameSite=Strict, Secure на HTTPS; срок сеанса 8 часов.
* Изменяющие запросы требуют действующей сессии и CSRF; проверяется Origin.
* Ошибочные входы ограничены приложением и Nginx.
* Просмотр `/watch/` требует входа; внутренние Nginx-маршруты недоступны извне.
* HLS-источник на 18080 по умолчанию разрешён только адресам из `origin_allow`.
  Это независимый от авторизации панели путь. `["all"]` делает его публичным.
* Настройки HTTPS, доменов и путей принимает только локальный установщик.

## Разделение прав

Эфир и панель работают от системного `ffpu`. Worker ограничены systemd:
ReadWritePaths, ProtectSystem, закрытый home, ограниченные ресурсы и адресные
семейства. Панель имеет узкое sudo-правило только на `cyrius-panel-admin` без
аргументов; helper сам валидирует действия, данные, пути и размеры изображений.

`NoNewPrivileges` для панели не включён, поскольку он блокировал бы этот sudo-helper.
Это осознанная граница доступа, а не общий root-доступ приложения.
`cyrius-admin` с операциями пользователей и HTTPS в sudo-правило не входит.

## Секреты

Не коммитьте:

* `deploy/settings.json`, токены, приватные SSH-ключи;
* `/var/lib/cyrius-panel/panel.db` и `secret.key`;
* `/root/*credentials*.json`;
* `/etc/letsencrypt/` и конфиги с секретами поставщиков;
* медиа, журналы, торрент-метаданные, историю операций и резервные копии.

`.gitignore` помогает избежать случайного добавления, но не исправляет утечку
уже закоммиченного секрета. В таком случае секрет сначала отзывают/меняют.

## Резервные копии

Храните их на сервере и отдельно на независимом носителе/хранилище, доступном
только администратору. Для SQLite используйте штатный online backup, а не простое
копирование открытого файла базы с WAL. Установленные фильмы резервируются отдельно
от приложения; GitHub не является резервной копией медиатеки.

Две независимые файловые системы не зеркалируют друг друга автоматически.
Права на файлы после восстановления должны соответствовать `ffpu` и
`cyrius-media`. Чужие источники или скачанные файлы не дают разрешения на показ.

проверяются отдельно. Этот репозиторий их не предоставляет.
