# Устройство системы

## Программы

Фронтенд — HTML/CSS/JavaScript, backend — Flask/Gunicorn. Обмен идёт через
`/api/*`. Вход защищён паролем, изменяющие запросы — CSRF и проверкой Origin.
Nginx завершает HTTPS и передаёт запросы на `127.0.0.1:8890`.

Для каждого канала отдельная Python-служба запускает FFmpeg. Она читает файл,
выбирает аудиодорожку, накладывает оформление и публикует MPEG-TS HLS.
FFmpeg работает с исходниками на чтение: готовые фильмы он не перезаписывает.

HLS-фрагменты целятся в 4 секунды, окно плейлиста — около 90 секунд, старые
фрагменты сохраняются около 10 минут и затем чистятся. При пакетном копировании
фактическая длина зависит от ключевых кадров исходника. Смена фильма отмечается
discontinuity. Совместимость с настроенным ранее Flussonic проверялась на MPEG-TS;
замена контейнера на fMP4 без проверки не рекомендуется.

Название фильма рисуется один раз в PAM через Pillow, затем накладывается FFmpeg.
Логотип из PNG при установке преобразуется в PAM. Это сохраняет совместимость
с прежней сборкой FFmpeg, где не было PNG-декодера и drawtext.

| 3 | Cyrius Kids HD | `KidsHD` | `cyrius-kids-hd` |
| 4 | Cyrius Horror | `Horror` | `cyrius-horror` |
| 5 | Cyrius Cinema HD | общий набор шести тем | `cyrius-cinema-hd` |
| 6 | Cyrius Ретро HD | `Retro` | `cyrius-retro-hd` |
| 7 | Cyrius Романтика HD | `Romance` | `cyrius-romance-hd` |

Cinema использует те же исходные файлы. Своё воспроизведение и видеокодирование
у него отдельное, поэтому он расходует CPU, даже если фильм есть в другом канале.
Каталог `CinemaHD` сохранён для совместимости, но автоматически не наполняется.

## Каталоги на сервере

| Каталог | Содержимое |
|---|---|
| `/opt/cyrius-panel/` | Установленные backend и фронтенд |
| `/usr/local/libexec/cyrius-*`, `cyrius_*.py` | Движок эфира и модули |
| `/usr/local/sbin/cyrius-panel-admin` | Ограниченный помощник панели |
| `/usr/local/sbin/cyrius-admin` | Полноценное локальное администрирование, только root |
| `/etc/cyrius/` | Настройки каналов, названий и сайта |
| `/srv/cyrius/media/<жанр>/` | Фильмы первого диска |
| `/srv/cyrius/disk2/media/<жанр>/` | Фильмы второго диска, если он подготовлен |
| `/srv/cyrius/media/<жанр>/Disk2/` | Bind-доступ к тем же файлам второго диска |
| `/srv/cyrius/assets/` | Исходные PNG, PAM и шрифт |
| `/etc/cyrius/panel-logos/` | Логотипы, сохранённые панелью |
| `/var/lib/cyrius-copy/<номер>/` | Текущее состояние, каталог и кеш метаданных |
| `/var/lib/cyrius-control/<номер>/` | Очередь, команда и подтверждение её выполнения |
| `/var/lib/cyrius-panel/` | Пользователи, аудит и ключ сессий |
| `/srv/cyrius/public-copy/<номер>/live/` | Временные HLS-фрагменты |
| `/srv/cyrius/public-copy/epg.xml` | ЕПГ для IPTV |
| `/srv/cyrius/public-copy/programme.json` | ЕПГ для панели |
| `/srv/cyrius/public-copy/channels.m3u` | Список каналов |

Очереди в JSON содержат **абсолютные пути**. Сохраняйте структуру каталогов при
миграции или пересоздавайте очереди. Одноимённые файлы на разных bind-монтированиях
не всегда можно hardlink-нуть; используйте физические пути на втором диске.

## ЕПГ и команды

ЕПГ обновляет таймер `cyrius-programme.timer` каждые 30 секунд. Он рассчитывает
ближайшие 24 часа по текущему фильму и порядку очереди. Будущие времена приблизительны;
ручное переключение меняет их. Без повтора очередь заканчивается.

Кнопка панели пишет команду с уникальным ID, worker проверяет её и создаёт ack.
Команды не выполняются повторно после подтверждения; устаревшие отклоняются.
Изменение очереди само по себе не прерывает текущий фильм. «Следующий» и запуск
выбранного фильма прерывают, поэтому интерфейс запрашивает подтверждение.

## Что не требуется

ffplayout и Transmission не являются зависимостями новой установки. Старый
сервер может ещё иметь веб-сервис ffplayout, но текущие каналы воспроизводит
собственный движок. Flussonic работает отдельно и получает HLS по сети.
Mac и открытая вкладка панели для эфира не нужны.
