# Управление после установки

## Службы и журналы

```bash
sudo systemctl status cyrius-panel.service
sudo systemctl status cyrius-copy@1.service
sudo journalctl -u cyrius-copy@1.service -n 50 --no-pager
sudo journalctl -u cyrius-panel.service -n 50 --no-pager
sudo systemctl list-timers cyrius-programme.timer
sudo cyrius-admin health
```

Номера каналов перечислены в `ARCHITECTURE.md`. `health` вернёт ненулевой код,
если хотя бы один из семи каналов остановлен; при поэтапном запуске это ожидаемо.

```bash
sudo systemctl stop cyrius-copy@1.service
sudo systemctl start cyrius-copy@1.service
sudo systemctl restart cyrius-panel.service
```

Перезапуск панели не останавливает эфир. Перезапуск worker прерывает его соединение
с FFmpeg, затем обычно продолжает тот же фильм около сохранённой позиции.
Останавливайте каналы штатно через systemd, не завершайте отдельный FFmpeg вручную.

## Забыли пароль

```bash
sudo cyrius-admin password --username admin
```

Пароль вводится скрыто и не попадает в историю команд. Сеансы этого пользователя
станут недействительными. Веб-панель не имеет доступа к этой root-команде.
Первоначальные данные и результат локального сброса сохраняются в root-only файле
`/root/cyrius-panel-credentials.json`. При смене пароля через браузер этот файл
не обновляется: действующий пароль может отличаться.

## Фильмы и русские названия

1. Передайте законченный файл в тематическую медиапапку.
2. Проверьте его в «Медиатеке»: название, длительность и аудиодорожку.
3. Исправьте русское название и сохраните очередь в панели.
4. Дождитесь смены фильма либо явно запустите выбранный с начала.

Глобальное соответствие `имя файла → название` хранится в `movie-titles-ru.json`.
Наличие русских букв в имени файла не доказывает наличие русской озвучки.
Автоматическая проверка речи по содержанию в проекте отсутствует.

Загрузка многогигабайтных видео через браузер и новый HTTPS-поставщик фильмов
пока не реализованы. Раздел торрент-загрузок показывает отключённое состояние.

## Логотип и формат изображения

В панели можно заменить PNG, размер и положение, изменить оформление названия.
По умолчанию настройки применяются на следующем фильме. Применение сейчас
перезапускает обработку около текущей позиции и может дать краткую паузу.

Изменения конфигов сохраняет ограниченный помощник. Резервные версии JSON
складываются в `/var/backups/cyrius-panel-config`. Исходные фильмы не меняются.
При отключении логотипа и форматирования можно вернуться к пакетному копированию,
но совместимость кодеков, звука и границ HLS тогда зависит от исходника.

## Если лагает

* Посмотрите CPU, скорость дисков и журналы worker.
* Сравните воспроизведение источника и потока после Flussonic.
* Убедитесь, что HLS-плейлист и сегменты регулярно обновляются.
* Проверьте IP CDN в `origin_allow`, firewall и доступность порта 18080.
* Проверьте кодек аудио: звук копируется, автоматического AAC-преобразования нет.
* Если CPU упирается в предел, уменьшите число одновременно кодируемых каналов
  или измените формат после оценки качества. Дополнительная RAM не кодирует видео.

Обновление `index.m3u8` ещё не доказывает исправный звук и показ на телевизоре:
финальная проверка всегда включает IPTV-приложение и смену фильмов.

## Обновление кода

`git pull` в каталоге репозитория **не заменяет установленные** файлы в
`/opt/cyrius-panel` и `/usr/local/libexec`. Автоматическое обновление не включено.

Сначала сохраните конфиги и согласованную SQLite-копию базы на сервере, изучите
изменения и проверьте их на отдельной машине. Затем обновляйте только изменённые
файлы. Worker перезапускайте по одному; новый установщик поверх действующей
инсталляции не запускайте. Пароли и TLS не пересоздавайте при обычном обновлении.
