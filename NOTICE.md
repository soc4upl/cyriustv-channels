# Права и сторонние компоненты

Собственный код и оформление CYRIUS включены для переноса проекта его владельцем.
Открытая лицензия на собственный код и логотипы не предоставляется: решение о её
выдаче остаётся за владельцем. Логотипы CYRIUS не являются общедоступными знаками.

В репозитории нет кинофильмов и прав на их публичный показ. Права на каждый
используемый фильм, озвучку и территорию распространения проверяются отдельно.

Сторонние компоненты:

* `src/panel/static/hls.min.js`: hls.js 1.5.18, Apache License 2.0.
  Уведомления: `docs/licenses/hls.js-LICENSE`; полный текст: `docs/licenses/Apache-2.0.txt`.
  https://github.com/video-dev/hls.js/tree/v1.5.18
* `assets/fonts/Montserrat-Light.ttf`: Montserrat, SIL Open Font License 1.1.
  Текст лицензии: `assets/fonts/OFL.txt`.
* Python, Flask, Werkzeug, Pillow, Gunicorn, Nginx и FFmpeg устанавливаются из
  пакетов Ubuntu; их бинарные файлы не включены в этот репозиторий.

Рабочая история сервера, пароли, сеансы, сертификаты, торрент-метаданные и резервные
копии с сервера в репозитории отсутствуют.
